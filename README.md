# 🎂 Happy Birthday Adah!

A mobile-friendly funny + lovely interactive birthday card using the photos uploaded in the conversation.

## Upload
Upload `index.html`, `style.css`, `script.js`, and the complete `assets` folder to the GitHub repository.

## GitHub Pages
Repository → Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.

All uploaded photos are kept as the original image files; the website only crops them visually inside its cards.
